# Responsive Portfolio Website

Welcome to my personal portfolio website built with HTML5 and Tailwind CSS.

## 🚀 Features
- **Responsive Layout:** Perfectly adapted for Mobile, Tablet, and Desktop screens.
- **Modern UI:** Styled using Tailwind CSS with glassmorphism effects and custom gradient accents.
- **5 Core Sections:**
  - **Hero Section:** Intro, Profile Image, Hire Me & Download CV buttons.
  - **About Me Section:** Personal bio and quick details grid (Name, Age, Email, Location).
  - **Skills Section:** Interactive cards highlighting core web technologies.
  - **Projects Section:** Showcase of featured applications with Live Demo and Code links.
  - **Contact Section:** Clean contact form UI.

## 🛠️ Built With
- **HTML5**
- **Tailwind CSS** (via CDN)
- **Font Awesome Icons**
